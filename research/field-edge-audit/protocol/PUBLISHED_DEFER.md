# Matched learned deferral methods

These are retrospective comparisons on the three previously inspected geography cohorts. This analysis locks this specification before measuring the new routers' held-out outcomes. The application contract is 20 archived draws of the same 128 Cornell labelling-pool paths, one 1280-dimensional frozen edge activation per photo, the same 224-pixel quality-75 source-balanced PlantDoc DINO decision, complete coverage, and the three original application-byte ceilings (10%, 25%, 50%). No held-out image is eligible for fitting or tuning. No new source, pretraining, label or test expert response enters the router at inference.

## Published algorithms

* Logistic OvA, Verma and Nalisnick, ICML 2022, equation 8. Fit one logistic score for each class against its complement, and one for the true-class agreement of the expert. In binary classification the two identically regularized class classifiers have opposite scores. Store just the positive-class logit with its negative implicit. Under the paper's additive logit cost representation, rank by the expert logit minus the stronger class logit. The zero-cost unrestricted decision is the published argmax. We use the equal class-loss multiplier (alpha=1) and stable logistic arithmetic. [Paper](https://proceedings.mlr.press/v162/verma22c.html) · [Author loss implementation](https://github.com/rajevv/OvA-L2D/blob/0998898feba805183b8fb37a88e4405dd86ecf8c/losses/losses.py) · [Author cost sweep](https://github.com/rajevv/OvA-L2D/blob/0998898feba805183b8fb37a88e4405dd86ecf8c/validation.py).
* CompareConfidence, as implemented and benchmarked by Mozannar et al., AISTATS 2023. Fit supervised class probabilities and a separate binary estimate of expert correctness. Subtract the maximum class probability from the estimated expert correctness probability. The binary softmax can be written as one sigmoid. With our fixed linear representation CC and OvA share their two trained heads; the risk rankings differ through the score transform. They are related decision rules. [Benchmark paper](https://proceedings.mlr.press/v206/mozannar23a.html) · [Author code, including the exact subtraction](https://github.com/clinicalml/human_ai_deferral/blob/94c05bcdb6822009835fe051dc11a0a878f3e6f4/baselines/compare_confidence.py#L219-L246).
* Two-stage cost-sensitive logistic routing, Mao, Mohri and Zhong, ICML 2025, equations 5–6. Set the two example costs to the local and cloud classification errors. For cloud-minus-local routing score s the objective per image is c_local log(1+exp(-s)) + c_cloud log(1+exp(s)). Fit this as ordinary logistic regression with one positive copy weighted by c_local and one negative copy weighted by c_cloud. Agreement on the correct answer contributes zero, and agreement on an incorrect answer contributes both terms. The local predictor is fit on the same 128 labels. To avoid teaching the router unrealistically low in-sample local error, derive local training costs from four stratified out-of-fold predictions within those 128. Fit the deployment local classifier on all 128. The service stays frozen. Ranking uses s. This is a direct reimplementation of the published two-expert objective. [Published paper](https://proceedings.mlr.press/v267/mao25c.html) · [Authors' full text, Section 4.1](https://cs.nyu.edu/~mohri/pub/rmdef.pdf).

Use L2-normalized symmetric INT8 edge activations and separately quantized linear decision heads throughout. The 128-label reference uses a balanced local logistic head with fixed C=1, liblinear, the previously frozen inference protocol and no retraining of the backbone. Use those same settings here. Each method is reported with unweighted examples to reproduce the conventional risk, and with the same inverse target-class-frequency weights as the joint system to target balanced accuracy. Weights are computed from the current training fold. Never rebalance the expert-agreement classes themselves. The balanced class head must reproduce the deployed 128-label reference. The Mao router fits zero-one error costs with these same observation weights. No local or target-label hyperparameter sweep is performed. The compared loss and ranking are the published mechanisms. The architecture, training size, finite-batch byte limit, JPEG transport, CPU simulation, and INT8 port are case-study adaptations; results are not reproductions of authors' original benchmarks.

## Accounting and fallback

Training happens at the service. Charge each actual 1,293-byte labelled-activation record and one 224px JPEG with an 8-byte image header per calibration image when training supervised cloud-error routing. The trained cloud model runs on those exact calibration photos at the service. Remote annotation reuses that already transmitted JPEG. Both reviewer arrangements therefore incur the same learned-router setup cost. Serialize each returned classifier or router to its real 1,294-byte wire representation. Binary OvA opposite class scores require only one class head. The original balanced uncertainty reference normally needs only its one classifier and the labelled activations (additional JPEGs for a remote annotator). Failing to afford a learned installation invokes the ordinary adapted INT8 plus confidence router if affordable, otherwise the published frozen-edge router. Never charge for an installation that the simulated system can see it cannot afford. Each row records desired and actual setup costs and the actual installed policy.

The primary end-to-end comparison debits setup before spending the remaining budget. A separate, explicitly prepaid-setup experiment gives every installed candidate precisely the same deployment query-byte ceiling. Every inference query costs the source-measured JPEG + 8-byte request + 12-byte probability reply. All methods receive the frame batch, local rank scores, fixed path tie-breaks and encoded lengths. As in the original budget study, sort by score from most to least helpful, use the budget-capped prefix with skips for nonfitting frames, and leave nonqueries with their own local classifier. This variable-threshold operating mode always fills the available capacity when possible, including scores below zero. It estimates a budgeted coverage curve beyond the default decision threshold. We archive all scores, local decisions, cloud decisions, JPEG lengths, selected masks, system predictions, byte counts, adaptation identities and fitted heads. There is no test-label policy selection.

In addition, the analysis calculates the unforced threshold-zero decisions for each published router as a diagnostic (without a hard cap) and records their bytes. Ordinary accuracy and classwise errors accompany balanced accuracy throughout.

## Limited expert-feedback sensitivity

Added after inspecting the all-128 expert-feedback results. The first observed comparison confounds the cost of querying 128 calibration photographs with the quality of the learned deferral scores. Preserve the original 128 ground-truth labels and use all of them to fit exactly the same balanced classification head. Fit each of the three published routers using cloud feedback only for the first 32 entries in each archived random draw (primary feedback fraction), with 8, 64 and the full 128 for sensitivity. Source order is fixed before observing these subset-feedback results. Subset weights are inverse frequencies of disease labels within the feedback subset. The 128 out-of-fold expert-cost labels for Mao are obtained from folds of the local 128-label draw as before; the router sees the selected subset and its cloud outcomes only. For locally available labels, the service receives just those selected JPEGs for router supervision. For remote annotation all 128 JPEGs are required anyway and the service may compute their predictions without extra communication. The full-feedback arm is therefore the ordinary remote-review comparator. All variants use the same service and greedy scheduler. Report every predetermined feedback size. The best observed size on a held-out cohort is an unimplementable upper envelope without an independent selection rule. No outcome-dependent model or choice of feedback size is deployed on any image.

### Identity tie-break correction

The limited-feedback stress test exposed a semantic defect in the shared scheduler's original path tie-break. When few feedback examples have differing errors, a fitted router can produce a constant score. Lexicographic ordering then reveals labels present in several public datasets' folder and file names. We replaced that tie-break for **all** of this comparison's methods and budgets with SHA256 of the salted original content digest, plus a second salted SHA256 of full identity used only to disambiguate identical bytes. Corpus paths remain join keys. These hashes are opaque to the scheduler and are used solely when severity scores are tied. The correction was made after inspecting the limited-feedback anomaly. It applies uniformly, with no selection using outcome quality. The reference is rerun and checked against all 360 previously measured charged outcome/byte triples.

## Reproduction

From the project root, `python scripts/published_defer.py` refits all 20 complete-feedback draws on the stored features. Use `--feedback-count 8`, `--feedback-count 32` and `--feedback-count 64` to rebuild the three nested-feedback sensitivity directories. For release-only replay, including Latvia without distributing source embeddings, run `python scripts/published_defer.py --replay results --out /tmp/defer-replay` or point `--replay` to a partial-feedback directory.

Each score archive includes aligned reference and expert decisions, local predictions, higher-is-more-urgent priorities, opaque tie-breaks and complete request/reply sizes. A row in the runs table identifies its cohort and site-local row index. To decode predictions and query masks use `np.unpackbits(array, axis=1, count=len(y))`. Reviewer placement is a setup-cost distinction. The two prepaid reviewer scenarios are numerically identical. The six published-method variants include arithmetic-related scores and class-weighting controls. The 20 seeds share testing images. Counts of runs or seed wins must not be interpreted as independent datasets.
