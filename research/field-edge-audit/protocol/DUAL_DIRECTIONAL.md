# Two-direction disagreement policy fixed before evaluation

This single additional candidate uses the released edge SUSPECT probability and the unmodified, source-balanced binary PlantDoc DINO head. There is one opportunity to rescue a missed disease and one to retract a false alert. The device computes its binary edge decision using float32 suspect probability at least 0.30. On an edge-negative image, upload only when its edge probability is at least a lower gate. After querying, alert only if the remote disease probability is at least the rescue threshold. On an edge-positive image, upload only when its edge probability is at most an upper gate. After querying, clear the alert only if the remote disease probability is strictly below the retraction threshold. A disabled branch sends no data and preserves the local decision. Only original binary disagreements can flip. Both sides use float32 probabilities. The source DINO produces a binary logit, converted by sigmoid in float64 and rounded for the float32 reply.

The candidates are fixed before computing their calibration or held-out errors. The rescue edge lower gates are [0, .05, .20]. The retraction edge upper gates are [.40, .70, .95, 1]. Each rescue gate is crossed with six remote cutoffs [.5, .6, .7, .8, .9, .95]; each retraction gate is crossed with six cutoffs [.5, .4, .3, .2, .1, .05]. Each branch also has a disabled option. Their Cartesian product contains 475 rules. The release threshold 0.30 is fixed. The finite grid and the endpoints enable complete upload on either branch and permit conservative restrictions.

Use all 450 candidates in the already frozen Cornell label pool to select a rule, with their original labels and without reweighting. The primary feasible set requires at most floor(original FN / 2) missed cases and strictly fewer false positives on this calibration pool. If several qualify, minimize in order calibration FP, total retracted alerts, calibration FN, and total application bytes consumed by inference on the calibration pool. Remaining ties use the fixed order given above, listing the disabled branch first and the rescue option as the outer loop. If the primary feasible set is empty, only consider candidates that strictly reduce both calibration counts. For this fallback minimize, in order, calibration FN, FP, retracted alerts, application bytes and grid order. If no candidate strictly improves both counts, install the original unchanged local policy. The baseline cannot be strictly improved on a calibration error count that is already zero. These are finite-pool selection constraints, with no future-population guarantees.

Fit writes an exact little-endian device configuration and an accompanying JSON with its SHA256, calibration identities, source weights, grid, errors and selection tier. Evaluation separately reads this immutable configuration. No score or label from the two test cohorts enters selection. The two evaluation cohorts have already been reported for previous locked candidates. A prospective Latvia target is reserved for a separate replay. Record every rescue and retraction against its reference label, including harm; distinguish counts and critical strictly simultaneous improvement from average rates.

## Communication protocol

The service hosts the unchanged pretrained PlantDoc-balanced model. To select parameters it has to receive the 450 target JPEGs plus the original local probabilities, because the lossy long-edge-224 JPEG differs from the local 160-pixel input. Each calibration record consists of four bytes of magic, a uint32 image ID, a binary32 edge probability, one local-reference byte and the actual JPEG bytes. A remote reviewer can inspect these same JPEGs and join the labels by image ID on the service. No separate image transfer is needed. Download one rule package containing the magic, a version byte, a flags byte and four float32 gates/thresholds. At deployment each query sends an eight-byte image-ID header and the actual long-edge-224 quality-75 JPEG; the response uses four-byte magic, uint32 ID and a float32 DINO disease probability. Received bytes are charged for every selected image, including queries where the two models agree. An all-disabled fallback already lives on the device and requires zero installation payload. The metadata JSON and reference file archives are research artifacts. The application traffic excludes transport headers, radio retries and model inference time. Camera, board and link energy are not measured.
