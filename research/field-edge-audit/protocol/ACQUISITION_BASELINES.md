# Shift-triggered acquisition and published review comparators

The label-purchase comparison reuses the same eligible target calibration stream, cap, human labels and measured packets for all policies. A frozen controller can retain its source classifier without buying any labels. Fixed acquisition, a paid pilot that stops, and a trigger that buys the remainder spend different numbers of labels under the same maximum. The study also budgets for spent pilot JPEGs when no new head is installed. Equal numbers of purchased labels are a separate sunk-cost decision comparison.

## Acquisition comparator

Rabanser, Günnemann and Lipton's BBSD-soft reduces each image to its vector of class probabilities, applies a two-sided two-sample KS test per dimension, and uses a Bonferroni-corrected 0.05 significance level. We include the two complementary binary probability coordinates, keeping the original correction. A frozen camera compares the source reference with the first sixteen unlabelled local calibration scores. The reference comprises the same 121 audited official PlantDoc held-out pictures across all three pipelines (four crops and the source split's original class mix). V2 reuses verified scores. V4 and V2-grid run the source classifier on the same original bytes, checked against SHA-256. This reference can also detect the four-crop to apple-only composition change. Its sorted 121 binary32 scores occupy 484 device bytes, installed with the source configuration. The experiment does not charge the common base camera to individual field windows. The grid pipeline uses the exported-scale host arithmetic, and its reference has many tied scores. A nominal KS significance level therefore need not be exact in this setting. [Detector and original empirical scope](https://proceedings.neurips.cc/paper_files/paper/2019/hash/846c260d715e5b854ffad5f70a516c88-Abstract.html) · [Pinned author test](https://github.com/steverab/failing-loudly/blob/42afd118237ded54c6ebef4a3417d8c1db44f76d/shift_tester.py) · [Pinned author adjustment](https://github.com/steverab/failing-loudly/blob/42afd118237ded54c6ebef4a3417d8c1db44f76d/shift_detector.py)

At a significant difference the wrapper requests its shared target-label quota, subject to affordability. Otherwise it retains the source classifier. This is the request-and-reverify (RR) structure evaluated by Ginart et al. with BBSD-soft as the anomaly signal. We use the resulting labels for one update in a finite window. The referenced monitoring publications did not evaluate this retraining policy or hard JPEG byte accounting. This comparison applies the published monitor and separates the study's choice of acquisition wrapper. [Request-and-reverify, Algorithm 2](https://proceedings.mlr.press/v151/ginart22a/ginart22a.pdf)

Run `python scripts/acquisition_baselines.py --quantization-config /path/to/tinyvision.json` to recreate the three camera reference columns after following the project’s model and dataset preparation. No target image or target label enters this reference.

## Review given purchased labels

Each candidate receives the same paid human labels, normalized INT8 activations and shared cloud decisions on the transmitted calibration photos. No evaluation reference enters the fitted model or the router. The common base head is class-balanced logistic regression serialized in the existing EQ01 format. EdgeBoost rank equivalence with absolute binary margin follows by strict monotonicity of its positive temperature-scaled top-two class gap. The fixed variant fits the temperature by NLL on out-of-fold scores and sets a float32 review cutoff for the requested fraction using calibration packet sizes. Its rank-only variant can compile away the temperature. OvA and CompareConfidence buy an extra packed head for cloud correctness and score using the published logit/probability comparisons, respectively. Mao's two-stage logistic cost gate compares edge and cloud errors on the paid examples using out-of-fold edge outputs. Diff-01 uses a two-hidden-layer MLP trained on out-of-fold edge probabilities, targeting binary expert correctness minus edge correctness for 20 full-batch Adam updates. Gatekeeper applies its hard-label binary objective to the final head, and the balanced CE comparison continues ordinary cross-entropy. Each of these last two returns a single refreshed head. The expensive ranker's weights are included in the downlink fee.
