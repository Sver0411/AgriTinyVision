# Published confidence cascade and component intervention

This follow-up was designed after the original three-site results. Site and seed are fixed, and no holdout score selects a policy. The comparison uses the same Cornell calibration identities, byte caps and source-balanced remote expert as the original benchmark.

## EdgeBoost

Said and Landsiedel, Computer Networks 269, 111437 (2025), use positive scalar temperature calibration by negative log likelihood and the difference between the largest and second-largest softmax probabilities, accepting confident predictions locally. [Journal paper](https://doi.org/10.1016/j.comnet.2025.111437) · [Author implementation, pinned](https://github.com/ds-kiel/EdgeBoost/tree/26abd91857989a542ef67c7fd59f619ee563f458)

Check the author offload function on the authors' stored CIFAR probabilities and seven original thresholds. Its percentages (rounded as in the original) must match our independently vectorized implementation. Do not compare CIFAR accuracy numerically with orchard accuracy. For the apple comparison provide EdgeBoost the identical adapted binary endpoint including the 128-label INT8 head. Train temperature on four stratified out-of-fold logits of the same 128 examples. The pretrained backbone and server match across all methods. The original uses pretrained multiclass models and a user-chosen threshold. For matched batched variable-byte ceilings, sort by its calibrated confidence in ascending order and apply the existing exact-cap packer. The binary margin for a signed logit z is tanh(|z|/(2T)). Score ordering is therefore independent of T for positive T. Report full per-image equality, any cutoff tie or numeric saturation, paid-setup and prepaid arms. A constant factor can be compiled away for rank-only routing. Also report a separate intact fixed-threshold gate selected on calibration data for each byte fraction using only calibration labels, JPEG lengths and scores. Thresholds need no target labels. Cap actual sends in fixed salted SHA-256 identifier order and count their realized usage. This second arm deliberately preserves threshold semantics and can underfill the allowance under transfer. Its up-front bytes additionally carry the serialized temperature and gate. Local calibration JPEG lengths are sender metadata (a uint32 per length if not already at the service). Results are finite-cohort replays, not an end-to-end reproduction of the original CIFAR/hardware setting.

## Latvian temporal component intervention

Reuse the pre-existing chronological split and the 20 exact 128-image draws shared with the fixed-expert diagnosis. Fit separate heads for the device (quantized normalized 1,280-D features, packed INT8) and remote expert (normalized 384-D DINO features and class-balanced L2 logistic regression, FP32 parameters) on early-site labels only. Compare two device heads (Cornell vs early Latvia) crossed with two server heads (unchanged PlantDoc expert vs early Latvia). The source weights are fixed incoming assets. The diagnostic shares access to the original Cornell resources and to the same 128 early Latvian labels in every arm. Downstream comparison reuses the same pre-paid 25% inference ceiling, JPEG charges, abstention protocol and 579 later held-out images. This isolates which head drives the change without confounding it with a smaller inference allowance. Quote cold acquisition costs of local activations, head and 128 calibration JPEGs separately. The cutoff is zero and cached expert decisions are independent of routing. Report full-review AUROC/BA/sensitivity and selected-review FP/FN/BA, by draw. This is a conditional intervention on classifier heads, not a controlled test of orchard, severity or camera effects.
