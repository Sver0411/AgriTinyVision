# Gatekeeper confidence tuning with a frozen remote service

Follow-up protocol, fixed before training or measuring any Gatekeeper head. Earlier Cornell, Kashmir and Latvia results for other policies have been inspected. This is an exploratory transfer of a published algorithm to these fixed experts and small calibration budgets.

Rabanser et al., Gatekeeper: Improving Model Cascades Through Confidence Tuning (NeurIPS 2025), give a hard-label binary-compatible objective (Equation 2) and a maximum-softmax classification gate (Equation 5). On each forward pass define correctness using the current head. A correct example contributes alpha times cross-entropy against its true label. A wrong example contributes (1-alpha) times KL of its predicted categorical distribution to uniform. Average over all examples, with correctness masks held fixed during each gradient step. Written for signed logit z and p=sigmoid(z), the gradient of the wrong-case KL term with respect to z is z*p*(1-p). Deploy the edge argmax and rank remote queries by smallest maximum softmax. In the binary setting this is exactly increasing absolute signed margin. The original authors explicitly report that their paper does not release code (checklist item 5). These are reconstructed equations, not the authors' source code or claimed reproductions of their original large-dataset performance.

Both arms start from the exact same archived 1,294-byte INT8 edge head fitted with that draw's 128 Cornell-labelled photos, and use exactly the same 224-pixel DINO service and three test pools. The central trainer already has signed activation records and their labels from the stage-one exchange. It decodes the stage-one head, applies the hard-label objective on those same 128 examples, encodes only the final head once, and ships it. The frozen FP32 backbone is common to both arms. The original paper fine-tunes classification networks under white-box access. We tune only the final head and use the project's existing INT8 transport and host evaluation. The server's output is never used to train this comparator. Contrary to an assumption used to motivate the source paper's ideal curve, our server may regress on edge-correct cases. We use only actual measured paired predictions.

The original articles report alpha sweeps with 0.1, 0.3, 0.5, 0.7, 0.9 for image classification. All five are evaluated. The primary alpha is 0.5, giving equal coefficients to the two terms. To make the head-only optimizer reproducible, predefine full-batch Adam with learning rate .001, betas .9/.999, epsilon 1e-8, no additional regularizer, starting from the decoded stage-one coefficients and bias. The primary horizon is 100 steps. Evaluate 20 and 400 steps at alpha=.5 as convergence sensitivities. Also evaluate alpha=.5 with inverse calibration-class frequencies in the loss and a plain cross-entropy-only continuation at the same 100 steps (both unweighted and class-balanced). These selected optimizer settings are study-specific. No test labels or outside label bank enter training or choose a result.

The same cold setup cost is charged for our baseline and all Gatekeeper arms. It consists of 128 measured signed activation records and the single 1,294-byte downloaded head. If the human labels are remote, reuse one transmitted JPEG per calibration picture, following the existing cost ledger. The two arms therefore have exactly the same allowance left for inference both with local and remote labels. If an update cannot fit, both use the original unmodified edge uncertainty router. Also compare predeployed heads with zero setup traffic. Use 10%, 25% primary, and 50% of full review traffic on each finite batch. A frame costs its actual JPEG length plus 20 application bytes. Sort by ascending absolute edge margin, break ties by path, skip oversize frames, and use the DINO prediction on selected images. Compare FP, FN, ordinary and balanced accuracy on each draw, bytes spent, selected pictures, and paired difference from the identically funded adapted edge router. Retain scores, head binaries, per-case query masks and decisions for verification.
