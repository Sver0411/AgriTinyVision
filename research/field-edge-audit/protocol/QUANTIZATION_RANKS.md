# Isolating edge numerical precision in the earlier head-to-head experiment

The question here is whether the ranking in the original paper changes under a different numerical representation of the same V2 backbone. This experiment retains the archived Cornell 20 draws of 128 paid labels, the original 1,353/384/1,190 test photographs and expert answers, JPEGs, five/five/one arrival orders, warm-up, remaining-byte controller, packing rule and treatment of an unaffordable installation. It is distinct from the later experiment that separates local target calibration data for every site.

Each trial compares (1) heads fitted and evaluated on FP32 features, (2) the identical FP32-trained heads applied to exported-scale host activation codes, and (3) every applicable classifier, temperature and learned router refitted on the same paid calibration identities using the grid features and then deployed on grid features. Reapplying the training wireformat to the grid features uses per-example signed-byte rounding just as for FP32 features. The original FP32 model uses its native decision cutoff of 0.30 when the update is skipped, and both frozen-grid arms use the corresponding host grid score at 0.30. The grid simulation has known output differences from ESP32-S3. Source paths are hashed for ties with the existing opaque salt. The original thresholded EdgeBoost batch arm uses its archived salted presentation order.

The primary scenario reproduces the 25% source-planned, remote-label, single-frame experiment in Section 3 Panel B. All seven archived FP32 policies must match stored per-image queries, final classes and total bytes in every draw and arrival order. A second set reproduces the retrospective 25% full-cohort ceiling under cold local labels, cold remote labels and prepaid setup in Section 4. All corresponding FP32 primary scores must agree with the prior table at numerical precision. The expanded comparison also reports the online results for the single-head balanced CE control, Gatekeeper, Diff-01 and Diff-Prob. Diff-Prob additionally receives the continuous frozen cloud score on the paid calibration images. Fallbacks, setup bytes, the identities of selected/predicted arrays (SHA-256), false positives, false negatives and final performance are retained by trial. In Kashmir ties caused by unaffordable setup are labeled as such.

Run `python scripts/acquisition_quantization_replay.py` in the prepared, authorized study environment. [Trial log](../results/acquisition_quantization_replay_runs.csv) · [Method summaries and ranks](../results/acquisition_quantization_replay_summary.csv) · [Paired rank reversals](../results/acquisition_quantization_paired.csv)

For each common draw, average the arrival orders before taking the A-minus-B balanced-accuracy difference. Positive means the first listed method improves on the second for that draw. The reversed-order column compares the signs of the two mean differences for the same methods before/after the serving-precision change; the count column compares signs per matched draw. Absence of an inversion is distinguished from a complete tie. Ranks use the minimum rank for ties, with the analytically identical uncertainty and EdgeBoost ranking represented once.
