## Equal access to labels and experts

Use the same 20 logged sets of 128 Cornell calibration IDs, the same final INT8 edge classifier trained using each complete draw, and the same frozen source-balanced DINO server on measured 224-pixel quality-75 JPEGs. Only target labels belonging to that draw may be used. The 1,353 held-out Cornell images, 384 fixed Kashmir pictures, and 1,190 Latvian scab pictures change no weights or settings. Owing to the single 128-label allowance, we construct the router's training data using four stratified, seeded folds within those 128 IDs. Fit the standard edge head on three folds, serialize and deserialize its INT8 coefficients, and obtain held-out signed margins for the fourth. Each router target thus uses an edge prediction made without that image's label. Deployment always uses the original archived 128-label head. The paper used 5,000–10,000 *additional* held-out examples and fixed classifiers. Cross-fitting under one label budget changes this design. Both the router and the proposed system may inspect all 128 labels. Any target labels on an external site remain withheld throughout training.

Convert each cross-fitted edge margin to a binary probability using sigmoid. The router takes five edge-side inputs: entropy (nats), its two class probabilities sorted largest first, and the two-dimensional argmax one-hot. This specializes the original top-ten feature to min(10, class count). The network uses 64 and 16 ReLU units and a linear output. The squared-error loss includes 0.001 times the sum of the squared weight tensors. We use reproducible Glorot uniform weights, zero biases, Adam at 0.0007, beta values 0.9/0.999, epsilon 1e-8 and a minibatch of 128. The paper reports 20 epochs. At this dataset size these give 20 optimizer steps. We additionally freeze an 800-step condition to approximate the optimizer step count in the paper's 5,000-image CIFAR setup. The longer fit is a sensitivity analysis. A second 800-step sensitivity weights each calibration class equally in the loss to match the study's balanced-accuracy endpoint. These are six fixed scores, with all results reported and no selection by evaluation labels. The trained float32 network is packed in a fixed little-endian format and deserialized for evaluation.
