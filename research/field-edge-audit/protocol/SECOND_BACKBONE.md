# Second edge backbone under fixed image and byte budgets

Written after analysis of the original MobileNetV2 experiment and before extracting or evaluating MobileNetV4 features for this benchmark. This is a post-hoc architecture transfer with locked comparisons, with no new field acquisition. No claim of general validity over a population of backbones is implied.

We use MobileNetV4-Conv-Small, introduced at ECCV 2024. The ImageNet-1k weights were trained by Ross Wightman/timm. The Hugging Face ONNX Community exports these weights under revision 3ba07f12712fa58fd6b3d661f9909c9e332c5005. Download the unchanged 15,086,122-byte FP32 model, SHA-256 ca5b8dbf490f54e83c5d72f787821565447ea94347935f6b834cf0a4af0e8d37. Apply its release preprocessing configuration, SHA-256 21bb2bccbd790ded22ca9ac77758578bae4d90d8fc578a612097bd38e9d40b2f (EXIF-corrected original images, RGB, bicubic shortest side 256 then center crop 224, divide by 255, and channel means 0.485/0.456/0.406 and standard deviations 0.229/0.224/0.225). Expose the input to the last Gemm by name from the graph. Verify its dot product with the original ImageNet weight and bias against the released output on every batch. These are features of the public FP32 graph running in CPU ONNX Runtime. This setup estimates communication and batch decisions, and does not measure a board deployment, power or latency.

Extract features for the 1,237 audited PlantDoc source-training identities used by the balanced DINO source head, all 1,821 Cornell images, all 384 selected Kashmir images, and all 1,190 Latvian images. Verify original SHA-256 values by path. The final CNN representation is quantized with a per-picture signed-byte scale; class heads are trained on the same normalized quantized representation used by the original protocol. Fit a class-balanced logistic source head with the established C=1 setting on PlantDoc labels only. Use a 0.5 binary cutoff throughout. Report frozen source behavior separately on complete image collections and target-adapted behavior on the original 1,353 Cornell holdout, the Kashmir/Latvia transfers and the original 579 later-date Latvian subset. No external cohort's labels enter head fitting, route priority or model selection.

Reuse the original 20 nested Cornell ID sets at 128 labels and the original Q75 224-pixel DINO server. Fit an independent full 128-label INT8 head per draw; count all transmitted activation records and the actual encoded final head. Charge remotely reviewed calibration JPEGs exactly as before. A 10%, 25% (primary) or 50% cap is a share of sending every image in the evaluation cohort through the same measured service. Sort original or updated edge scores by distance from their own 0.5 probability cutoff, equivalent to absolute signed logit. A query includes measured JPEG length plus 20 bytes. If an update does not fit, use the source head as in the first-backbone protocol. Compare source only, full remote reference, source confidence uploads, target update only, target + random review averaged over the same 20 path-sorted pseudorandom orders, and target + selective review. Include cold local and remote human review. Report a warm predeployed-head sensitivity. Compare two same-price additional controls fixed in the earlier protocol: true-label Gatekeeper (alpha .5, 100-step Adam preserved), and class-balanced cross-entropy continuation for the same 100 steps. Both fine-tune only this backbone's fitted layer and return the final head once. All weights, scalar classifications, query accounting and raw-file digests are replayable. Large feature caches and model weights are stored only under ignored data/raw. Restricted Latvian photos and embeddings are excluded from delivery.
