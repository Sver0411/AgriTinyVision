Offline study specification, 27 November 2026
Written after inspection of the historical 60-image audit and before examining new backend results. Exploratory local specification, not a public preregistration.

Freeze the AgriTinyVision v0.1.0 binary decision at 0.30 and the independent 38-class backend's summed nonhealthy probability at 0.50. No fine-tuning. PlantDoc uses all eligible official test photos for the 4 crops. Report the group outside the earlier 60 images separately, with exact and perceptual duplicates flagged where available. FGVC7 uses the 1,821 release-labelled Train_0..1820 orchard photos; no fitting on these images. Treat the two sources separately. Frozen FP32 on CPU is the device-reference model for extended data; only the 60 released measurements are physical INT8.
Main payload: longest side 224, JPEG Q75; 112 with identical quality is a sensitivity analysis. Primary estimand: all-image binary accuracy change from replacing edge predictions by server predictions. Also report repairs, regressions, false positives / negatives, balanced accuracy, crop-conditioned score as a secondary variant, and the zero-traffic always-alert baseline. Record actual JPEG payload bytes.
Secondary fixed-batch routing: at 5, 10, 25, 50 or 100 percent of the cost of uploading all 224 images, compare confidence-first (absolute distance to the published 0.30 threshold), seeded-random, smallest-first and an unattainable oracle. Packing may skip frames exceeding remaining budget. Describe buffer requirement. Same byte budget for both JPEG sizes.
Audit the fixed all-upload configuration by revealing 10, 25 or 50 labels, capped by the available pool. Compare uniform draws from model disagreements with uniform draws from all images, after computing frozen predictions in shadow mode. Report equal-tailed exact 95% finite-population inference and analytic correct-sign probability using full labels only for retrospective power evaluation. Report any zero effects. Costs for acquiring shadow outputs and for manual labels must be kept separate. Each interval is pointwise at a preselected budget; no post-selection or repeated-look protection.

Secondary specialist extension, before extracting any specialist results. To distinguish the effect of a backend designed for Internet field imagery, freeze a pretrained DINOv2-small encoder and fit one regularized linear head on eligible official PlantDoc TRAIN images alone, then compare on decontaminated PlantDoc TEST and the FGVC7 transfer set using the main 224 JPEG. This intervention changes both encoder and head training data; it does not isolate their individual effects.

Target-assisted experiment, specified before extracting any local head/adaptation results. Unit is a nonconflicting near-duplicate component in FGVC7. Group by 64-bit perceptual hash, Hamming distance at most 4. Retain one representative per component. Assign about a quarter to an annotation bank by stable identifier hash and the remainder to a common holdout. Within the bank draw nested sets of 8, 32 and 128 labels under 20 predetermined random seeds. Compare unchanged edge, score-only recalibration, replacement of the edge final head on frozen FP32 features with serialized INT8 weights, and a DINOv2 remote head fit to the same labels. Use balanced logistic regression with fixed regularization for the learned heads. Report fixed-holdout balanced accuracy, ordinary accuracy, variation from calibration-set selection, uplink/downlink payload separately and sensitivity if the annotator also needs to receive a JPEG. Distinguish this supervised scenario from zero-target-label tests.

External transfer stress test. Before inspecting third-source predictions, select 128 processed images from each of the three released Kashmir apple classes by SHA256 of the release filename with a fixed salt. Use the pinned AgML Parquet mirror of the Yatoo/Sharma collection. The source includes augmented photographs with unreported parent labels in this mirror; evaluate a finite processed-image pool only, do not treat 384 rows as independent farms, trees or original leaves and do not compute an image-iid significance test. Freeze all trained Cornell and PlantDoc heads. Count the shift in class-specific performance without fitting or tuning on Kashmir labels.

Joint decision analysis, specified before seeing target-assisted accuracy. On exactly the same Cornell supervised holdout as the new compact head, compute the least JPEG bytes that even a label-aware router would need to match a candidate head's balanced accuracy starting from the original frozen edge. Grant the router a free oracle choice of 112/224 MobileNet or 224 PlantDoc-specialist output per frame and the true label. Take the cheapest correcting payload per edge error. For a fixed number of healthy corrections, use the cheapest healthy prefix and the least diseased prefix meeting the required balanced-accuracy gain; minimize over feasible counts. If no such prefixes exist, mark unattainable. Report the supervised head's annotation and data costs separately. This benchmark applies to the specified backend menu and original edge only.
