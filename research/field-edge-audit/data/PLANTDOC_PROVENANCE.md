# PlantDoc host inference and duplicate screening

The input is the official cropped classification repository at commit `5467f6012d78d1c446145d5f582da6096f852ae8`. The Git tree contains 2,342 training images and 236 test images across 27 source labels. We enumerated Git objects directly. Six training pathnames in this revision collide with other filenames on a case-insensitive filesystem, so their exact pinned blobs were read directly from the object store. PlantDoc is internet-sourced, and the available files lack reliable plant, orchard or camera-session identifiers. [Dataset, paper citation and CC BY 4.0 license](https://github.com/pratikkayal/PlantDoc-Dataset/tree/5467f6012d78d1c446145d5f582da6096f852ae8)

AgriTinyVision's v0.1.0 FP32 ONNX graph has SHA-256 `350c32d88d19eb16dca7d905036d2c99a716a3938b91f52715349e43ee6ab909`. Its published metadata, queried alongside the graph, supplies the normalization and index of the positive logit. The field report and archived per-image model/board pairs are pinned to repository commit `16e7a2fdec43c02258f22e85b085ac269345e124`. [Model release](https://github.com/Sver0411/AgriTinyVision/releases/tag/v0.1.0) · [60 archived device/reference pairs](https://github.com/Sver0411/AgriTinyVision/blob/16e7a2fdec43c02258f22e85b085ac269345e124/reports/field_validation/INFERENCE_PARITY.json)

The analysis computes file SHA-256, orientation-corrected RGB pixel SHA-256 and a 64-bit DCT perceptual hash for every official test/development image and all 2,792 actual PlantVillage files in the frozen model's data manifest. All 2,792 files were verified against their published file digests. The reference subsets contain 1,964 training, 411 validation and 417 test images. The code uses the model project's perceptual hash and screens at Hamming distance four. Records of candidate pairs preserve the hashes' evidence type. Similar cropped or rephotographed leaves can remain unmatched. [PlantVillage source](https://github.com/spMohanty/PlantVillage-Dataset/tree/7f7ecc7e1eaca78107e3affe7cb5abd9427e139a) · [Frozen model's split manifest](https://github.com/Sver0411/AgriTinyVision/blob/16e7a2fdec43c02258f22e85b085ac269345e124/data/manifests/plantvillage_split.json)

The 15 matching test/training pairs involve 14 different PlantDoc test images. Eleven pairs share the complete file, one shares the decoded pixels, and three pass only the perceptual threshold. No candidate was found against the PlantVillage source files or between PlantDoc test images. The resulting conservative cohort comprises 222 images, of which 121 depict the four training crops. Five of the 60 archived board inputs match the official PlantDoc training split. These matches concern a comparand trained on PlantDoc; the AgriTinyVision model was trained on PlantVillage. There are 167 de-duplicated test images outside the archived board set.

The inferred target assigns healthy versus symptomatic according to the explicit class mapping in `scripts/run_plantdoc.py`. The four training crops are apple, bell pepper, potato and tomato. Binary decisions use a frozen 0.30 threshold. The three-state policy uses 0.20 and 0.40 plus the frozen quality gate. With the model repository’s Pillow 12.3.0 dependency, the 160-pixel RGB input hashes for all 60 archived hardware images reproduce byte for byte. Recomputed FP32 probabilities deviate by at most 5.1×10⁻⁷ from archived FP32 probabilities and all 60 archived FP32 triage states agree. The hardware columns contain existing board probabilities and decisions on those 60 inputs only. New CPU inference times measure ONNX execution on the host.

Run the following from the project root to rebuild the input cache and output tables.

```sh
python scripts/fetch_plantdoc.py
python scripts/run_plantdoc.py
```

The locked comparison used Python 3.12, Pillow 12.3.0, NumPy 2.5.5, SciPy 1.18.1 and ONNX Runtime 1.32.0 on CPU. `results/plantdoc_logits.csv` includes all official test rows, the source path join key, exclusion flags, the two raw FP32 logits, score, quality measurements and optional board record. `results/plantdoc_overlap.csv` contains every observed pair. `results/plantdoc_inference_summary.json` gives exact denominators and runtime versions. The complete fingerprint index is `data/features/source_fingerprints.csv`.
