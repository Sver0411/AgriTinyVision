# Frozen DINOv2 feature tables

Run `scripts/field_specialist.py plantdoc` and `scripts/field_specialist.py fgvc` after generating the two archived 224-pixel JPEG manifests and payload directories with `scripts/server_backend.py`. Then run `scripts/field_specialist.py head`. The extractor hashes every JPEG and checks its byte count against the actual transmission manifest. On CPU it uses the unmodified, public FP32 DINOv2-small ONNX graph at revision `c2bb04a51fab207c420665f1946016107bffc701`. Its SHA-256 is `83141175ec78b4ff9a2bb58a4c7c264ba0054d1c2e122e5a8114b79a8d4179ea`; the upstream preprocessor configuration hashes to `14e780d86fa1861f8751f868d7f45425b5feb55c38ca26f152ca5097ab30f828`. It decodes the archived JPEG, bicubically rescales its shortest edge to 256, center crops 224×224 and applies the supplied ImageNet affine normalization. [Original DINOv2-small model](https://huggingface.co/facebook/dinov2-small) · [Pinned ONNX conversion](https://huggingface.co/Xenova/dinov2-small/tree/c2bb04a51fab207c420665f1946016107bffc701)

Each `.npz` can be loaded using `np.load(file, allow_pickle=False)`. `cls` is float32 with one 384-dimensional raw final-layer class token per row. The fields `dataset`, `source_path`, `split`, `source_label`, `crop`, `y`, `source_sha256`, `jpeg_sha256`, `jpeg_bytes`, `jpeg_quality` and `long_edge` have exactly the same first dimension and order. The unique join key across datasets is `(dataset, source_path)`. Positive labels denote disease symptoms. PlantDoc contains 1,242 official training images from four crops and all 236 official test images. The Cornell archive has 1,821 public labeled apple-orchard images. The Cornell split name identifies its official labeled data source; the primary specialist treats the entire Cornell data set as an external test. The scalar fields `model_revision`, `model_sha256`, `preprocessing_sha256`, `input_manifest_sha256`, and `elapsed_seconds` record provenance.

The linear head uses unit-length L2-normalized tokens, a fixed L2-regularized binary logistic regression with C=1, an intercept and fixed probability cutoff 0.5. All training data are from the PlantDoc official training split; exact duplicate JPEG payloads enter at most once and conflicting groups are discarded. The fitted coefficient, intercept, class labels and training source paths are stored in `dino_plantdoc_head.npz`. Dataset fingerprints and training identifiers are recorded in `results/specialist_provenance.json`. The source weights are pretrained; pretraining image membership is not fully auditable from the public release.
